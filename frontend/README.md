# TrustLens

**TrustLens** is an explainable, rule-based digital image analysis web application.
It examines uploaded photographs, identifies indicators associated with filtering
and editing, and produces an estimated **Trust Score** between 0 and 100.

Every value shown is calculated from the uploaded image — nothing is randomized,
hardcoded, or generated by a machine-learning model.

> ⚠️ **TrustLens is a prototype.** The Trust Score is an _estimate_ based on
> selected heuristic image characteristics. It does not prove whether an image
> was edited or is authentic. Lighting, camera quality, compression, resizing
> and natural image variation can influence the results.

## Overview

TrustLens takes an uploaded image (JPG or PNG), runs nine feature calculators
in its analysis engine, and fuses the results into a single weighted Trust Score
using a transparent formula:
R = Σ(wᵢ · rᵢ) / Σ(wᵢ) # weighted risk
T = (1 − R) × 100 # Trust Score

The results dashboard shows the actual measured value for each feature, its
assigned risk level, and a plain-English explanation of what it means.

**What TrustLens is:**

- An explainable, rule-based image analysis tool.
- A transparent scoring pipeline where each feature's contribution is visible.

**What TrustLens is not:**

- A scientific forensic instrument.
- A guaranteed detector of edited images.
- A trained machine-learning classifier.

## Installation

### Prerequisites

- **Python 3.10 – 3.12** (recommended: 3.12)
  > Python 3.14 is not yet supported because NumPy/OpenCV do not have prebuilt
  > wheels for it on all platforms. If you're on 3.14, install Python 3.12
  > alongside and create the virtual environment with `py -3.12 -m venv venv`.
- **Node.js 18 or later**

### 1. Clone / unpack the project

```bash
cd TrustLens

cd backend
python -m venv venv
# macOS / Linux:
source venv/bin/activate
# Windows:
venv\Scripts\activate

pip install --upgrade pip
pip install -r requirements.txt

fastapi==0.115.6
uvicorn[standard]==0.34.0
python-multipart==0.0.20
opencv-python==4.10.0.84
Pillow==11.0.0
numpy==2.1.3

To verify :-  python -c "import cv2, numpy, PIL, fastapi, multipart; print('all imports OK')"

FRONTEND :-
cd ../frontend
npm install

```
